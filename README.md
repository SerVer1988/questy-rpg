# Questy RPG — AI Fox v1.0

Однофайловое веб-приложение Questy RPG. Проект пока работает без сборки и установки зависимостей.

## Запуск локально

1. Скачайте `index.html`.
2. Откройте файл в современном браузере (Chrome, Edge или Firefox).
3. Данные приложения сохраняются в `localStorage` этого браузера. Для резервной копии используйте встроенный экспорт данных, если он доступен в приложении.

## Публикация через GitHub Pages

1. Создайте репозиторий `questy-rpg` на GitHub.
2. Загрузите в корень репозитория файлы `index.html`, `README.md` и `.gitignore`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. После публикации сайт появится по адресу вида `https://ВАШ-ЛОГИН.github.io/questy-rpg/`.

Публикация может занять несколько минут. GitHub Pages использует `index.html` как стартовую страницу.

## Важно о безопасности

- Не добавляйте API-ключи, пароли, токены или персональные данные в файлы репозитория.
- В этой версии пользователь может ввести OpenAI API key в интерфейсе приложения. Прототип отправляет запросы напрямую из браузера; ключ сохраняется в локальном хранилище браузера. Это допустимо только для личного тестирования и не является безопасной архитектурой для публичного продукта.
- Перед запуском для других пользователей нужно перенести обращения к OpenAI на собственный серверный proxy и не раздавать секретный ключ браузеру.
- GitHub Pages — статический хостинг; серверный proxy на нём не запускается.

## Технологии

HTML, CSS, JavaScript, Tailwind CSS CDN. Сборка не требуется.
